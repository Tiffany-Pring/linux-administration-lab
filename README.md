# 🐧🌲 Linux Administration & Security Lab

*Exploring Linux, one command at a time.*

## 🍃 Project Overview

This hands-on Linux administration lab was completed as part of my NPower cybersecurity training.

The goal was to practice configuring and managing a Linux environment while learning how system administration supports cybersecurity.

## 🛠️ Skills Practiced

- Linux Command Line Interface (CLI)
- File and Directory Management
- User and Group Administration
- File Permissions and Access Control
- Backups and Data Compression
- Basic Shell Scripting

---

## 🌿 Part 1 — Creating a Company Filesystem

Created a structured company-style filesystem using Linux commands.

**Security connection:** Organized directories and controlled file access support secure system administration.

## 🔐 Part 2 — Users, Groups & Permissions

Configured Linux users, groups, and permissions to manage access to files and directories.

**Security connection:** Proper permissions help enforce least privilege and reduce unauthorized access.

## 📦 Part 3 — Backups & Data Compression

Practiced creating directory and configuration backups and compressing data.

**Security connection:** Backups support data recovery and system availability.

## 💻 Part 4 — Script Creation

Created scripts to practice automating Linux tasks.

**Security connection:** Scripting can improve consistency and reduce repetitive administrative work.

---

## 🔎 What I Learned

This lab helped me better understand Linux system administration, access control, and the importance of protecting system files.

I especially enjoyed working through commands, troubleshooting, and understanding why each configuration mattered.
